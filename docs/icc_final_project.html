ctrl_*.m 4 함수 — 설계 대상

파일설계 대상핵심 요구

Part (c)

각 제어기 설계 출발점 — 어떻게 시작할 것인가

Step 01 ctrl_lateral · AFS + ESC

목표 — driver 조향 위에 보조 조향을 더해 yaw rate 를 추종하고, slip angle 폭주를 막는다.

출발점

  1. 먼저 yawRateRef 를 bicycle 정상상태 식으로 계산한다 — 이것이 추종 목표: $$ r_{\text{ref}} \;=\; \dfrac{v_x\,\delta_{\text{driver}}}{L \,+\, K_{us}\,v_x^{\,2}} $$ $L$ = wheelbase, $K_{us}$ = understeer gradient.
  2. AFS: yaw rate 오차 $r_{\text{ref}} - r$ 에 PID 를 걸어 보조 조향각을 만든다.
  3. ESC: $|\beta| > \beta_{th}$ ($\approx 3°$) 일 때 driver intent 반대 방향으로 yaw moment 인가 (β-limiter).

방향

  • 속도 적응: 같은 게인이 저속/고속에서 다르게 동작 — gain scheduling $K(v_x)$ 권장.
  • anti-windup: 적분기 clip. saturation 동시 발생 시 폭주 방지.
  • saturation: |δ_AFS| ≤ MAX_STEER_ANGLE.

PID 가 출발점. 여유 있으면 bicycle state-space + LQR 로 확장 (가점 +2).

→ KPI 영향

  • A3 yawRateOvershoot / riseTime / settling (12pt) — yaw rate 추종 게인이 직접 결정. Qr ↑ → rise 빨라지지만 overshoot 위험. 너무 빠른 응답은 OFF baseline 보다 OS 가 커져 점수 0 위험.
  • A1 / A4 / A7 / D1 sideSlipMax (23pt) — ESC β-limiter (Kβ, βth) 가 결정적. β 임계 낮출수록 개입 빨라지지만 A4 Kus 추적 오차 ↑.
  • A1 / A7 / D1 LTR_max (14pt) — yaw rate 추종 정확도 + ESC 차동 brake 분배가 transient roll moment 감소.
  • A4 understeerGradient (5pt) — 정상상태 rref 계산식 정확도 + steady-state error 가 핵심.
Step 02 ctrl_longitudinal · 속도 + ABS

목표 — vxRef 추종 + 휠 잠김 (slip ratio 폭주) 방지.

출발점

  1. 속도 오차 $v_{xRef} - v_x$ 에 PI 를 걸어 총 종방향 힘 $F_x$ 산출.
  2. $F_x \ge 0$ → 가속 (brakeRatio = 0), $F_x < 0$ → 제동 (brakeRatio 비례).
  3. ABS: 휠 slip ratio $\kappa$ 가 target $\kappa_{\text{ref}} = -0.12$ ($\mu_{\text{peak}}$) 를 추종하도록 brake torque 조절.

방향

  • 저크 제한: 힘 변화율 $|dF_x/dt|$ 을 LIM.MAX_JERK 안으로.
  • 가속 한계: $|F_x| \le m \cdot a_{x,\max}$.

→ KPI 영향

  • B1 absSlipRMS (5pt) — ABS 의 핵심 직접 측정값. 각 휠 |κ| 가 κref ≈ 0.12 근방에 유지되면 RMS ≤ 0.10 충족. PI 만 잘 구현해도 만점 가능.
  • B1 stoppingDistance (5pt) — 시나리오가 강한 brake 를 직접 인가하므로 ABS 의 brake release 가 길이를 좌우. κref 를 -0.10~-0.15 사이에서 선택 — 너무 작으면 안 멈춤, 너무 크면 lock. peak μ 활용 시 MFDD 가 μg 에 근접해야 짧아짐.
  • D1 (간접) — D1 도 braking 포함하므로 ABS 가 작동 — 단, cornering 중이라 brake release 가 lateral grip 보존에 도움 (sideslip 안정).
Step 03 ctrl_vertical · CDC (반능동 서스펜션)

목표 — 4륜 감쇠 계수를 실시간 조절해 승차감 + 안티롤 동시 달성.

출발점 — Skyhook 알고리즘

  1. 각 휠에 대해 body 수직속도 $\dot z_s$ 와 서스펜션 상대속도 $\dot z_{\text{rel}}$ 의 부호를 본다.
  2. 부호가 같으면 감쇠 크게 (cMax), 다르면 작게 (cMin): $$ c_{\text{sky},i} \;=\; \begin{cases} c_{\max} & \dot z_s \cdot \dot z_{\text{rel}} > 0 \\ c_{\min} & \text{otherwise} \end{cases} $$

방향

  • 빈도 분리: body bounce (1–2 Hz) 와 wheel hop (10–15 Hz) 는 다른 전략 필요 — Hybrid (Skyhook + Groundhook) 권장.
  • 안티롤 보상: 횡가속도 $a_y$, roll 각도 $\phi$ 에 비례해 좌우 휠 감쇠 차등 (외측 ↑, 내측 ↓).
  • 범위 제한: CTRL.VER.cMin ≤ c ≤ CTRL.VER.cMax.

→ KPI 영향

  • 수치 P1 KPI 직접 영향 X — 정량 70 점에 직접 포함되지 않음. 그러나 보고서 (정성 30 점) 의 ride comfort / handling 평가에 핵심.
  • 가점 C1 / C2 (+2pt) — Single Bump / Sine Sweep 시나리오에서 aw,rms (ISO 2631 가중 RMS) 또는 peak 가속 감소 시 인정.
  • 간접 LTR 효과 — anti-roll 보상이 들어가면 A1 / A7 / D1 의 transient LTR 약간 감소 가능. 단 주효과는 ESC.
Step 04 ctrl_coordinator · Allocation

목표 — 횡·종·수직 제어기의 출력을 실제 actuator 명령으로 변환 + 물리 한계 검사.

출발점

  1. 조향: AFS 조향각을 그대로 전달 + saturation.
  2. ESC yaw moment → 4륜 brake 차동: track 반거리를 lever arm 으로 사용 $$ \Delta T_f \;=\; \dfrac{M_z}{2\,(t_f/2)},\qquad \Delta T_r \;=\; \dfrac{M_z}{2\,(t_r/2)} $$ 전·후 배분 비율 60:40 정도가 표준.
  3. 종방향 제동: 4륜 균등 분배 (lonCmd.Fx_total < 0 일 때).
  4. 감쇠 명령: ctrl_vertical 출력을 그대로 전달.

방향

  • 마찰원 제약: 종 + 횡 동시 인가 시 $\sqrt{F_x^2 + F_y^2} \le \mu F_z$ 위반 검사, 위반 시 scale down. 가점 +3.
  • WLS allocation: simple split 대신 weighted least squares 로 4륜 토크 분배 — 가점 +3.

→ KPI 영향

  • 가점 마찰원 (+3pt) — 검사 + scale-down 구현 시 직접 가산.
  • D1 (cornering + braking) 안정성 — 마찰원 scale 이 작동하면 종 brake 가 횡 grip 침범 방지 → sideslip / LTR 폭주 방지.
  • B1 stoppingDistance 간접 — amax 마진 (예: 0.95·μg) 이 너무 보수적이면 brake authority 가 깎여 stopping 길어짐. cornering 없는 직진 제동 시 마진 완화 고려.
  • 모든 시나리오 LTR — Mz 의 4륜 분배 비율 (전:후) 이 transient roll 에 영향. 60:40 표준이 균형점.
Part (d)

설계 전략 — 점수 우선순위와 Trade-off

한 번에 모두 잘 만들기는 어렵다. 영향력 큰 함수부터 작업하고, 시나리오 간 trade-off 를 의식적으로 선택.

전략 1 구현 우선순위 — 점수 기댓값 기준
순위 함수 영향 KPI 최대 점수 난이도
1 ctrl_lateral A3 + A1 + A4 + A7 + D1 횡 KPI 전부 ~55 중 — bicycle 모델만 알면 PID 시작 가능

전략 2 Trade-off 매트릭스 — 한 곳 좋아지면 다른 곳 나빠진다
설계 결정 좋아지는 KPI 나빠지는 KPI
강한 ESC β-limiter (Kβ ↑, βth ↓) A1 / A7 / D1 sideSlip A4 Kus tracking, AFS 와 conflict
공격적 LQR Qr (yaw rate weight) A3 riseTime / settling A3 overshoot ↑ (OFF baseline 통과 위험)
Reference shaping (yaw rate LPF, τ ↑) A3 overshoot A1 / D1 LTR ↑ (response 지연)
공격적 ABS κref = -0.15 B1 stoppingDistance (μ peak 활용) B1 absSlipRMS ↑
마찰원 amax 마진 확대 (1.0·μg) B1 brake authority D1 cornering 안정성 ↓
4륜 brake 전축 편향 (70:30) 안정성 (under-steer 경향) LTR (전축 하중 ↑)

해석 — 6 시나리오 점수 합계가 최대인 동작점을 찾는 게 목표. 1 시나리오에 over-fitting 하면 다른 시나리오 폭주.

전략 3 5 대 함정 — 0 점 위험을 만드는 흔한 실수
  1. OFF baseline 미달 — 채점식이 val_on >= val_off 면 즉시 0. 컨트롤러가 자연 응답보다 나빠지면 점수 무. 약하게 시작해 점진적으로 강화 권장.
  2. Anti-windup 누락 — LQI / PI 적분기 폭주 시 step input 에서 huge overshoot. clip + back-calc 둘 다 필요. ctrlState.zInt = max(-z_max, min(z_max, ...)).
  3. Saturation 무시 — AFS ±5° / brake ±MAX_BRAKE_TRQ 한계 무시한 게인. saturation 발생 시 적분기 끄거나 (back-calc) tanh soft sat 사용.
  4. 시나리오 over-fitting — A3 step 에 최적화 → A1 DLC LTR 폭주. 매 변경 후 6 시나리오 모두 grade.m 으로 검증.
  5. 참조 모델 오류 — bicycle steady-state 식 $r_{ref} = v_x\delta/(L + K_{us}v_x^2)$ 의 파라미터 (L, Kus) 가 plant 와 일치하지 않으면 tracking error 가 항상 잔류. veh_set.m 의 값 확인.

KPI 사전

Part (a)

핵심 5 변수 — r, β, κ, Kus, LTR

yaw rate · $r$, $\dot\psi$

rad/s핸들링 응답

차량이 수직축 (z) 기준 회전하는 각속도. 부호 컨벤션: 위에서 봤을 때 반시계 (+).

$r \;=\; \dot\psi,\qquad r_{\text{ref}} \;=\; \dfrac{v_x\,\delta}{L + K_{us}\,v_x^{\,2}}$
참고값범위
일반 주행0.1 – 0.3 rad/s
급선회0.5 – 0.8 rad/s
위험 임계> 1.0 rad/s

slip angle (사이드 슬립) · $\beta$

rad (출력 deg)안정성

차량 진행속도 벡터와 차체 종축 사이의 각도. “차가 옆으로 미끄러지는 정도”.

$\beta \;=\; \arctan\!\Bigl(\dfrac{v_y}{v_x}\Bigr) \;\approx\; \dfrac{v_y}{v_x}$

왜 yaw rate 만으론 부족한가: $r$ 만 잡으면 차가 회전하지 않고 옆으로 미끄러질 수 있음 (드리프트). $\beta$ 는 진행방향 이탈을 측정.

임계값의미
정상$\beta < 2°$제어 가능
주의$2° \le \beta \le 4°$운전자 보정 가능
위험$\beta > 4°$숙련자만 회복
제어불능$\beta > 7°$일반인 회복 불가

slip ratio · $\kappa$

무차원가속/제동

휠 회전속도와 차량 속도의 비율 차이.

가속: $\kappa = \dfrac{R_w\,\omega - v_x}{R_w\,\omega}$   ·   제동: $\kappa = \dfrac{R_w\,\omega - v_x}{v_x}$

부호 컨벤션: 가속 (+) · 제동 (−). ABS target $\kappa = -0.12$ (제동, $\mu_{\text{peak}}$).

영역값의미
미마찰$\kappa \approx 0$pure rolling
$\mu_{\text{peak}}$$|\kappa| \approx 0.10 – 0.15$ABS 목표
미끄러짐$|\kappa| > 0.15$$\mu$ 감소
완전 잠김 / 헛돌기$|\kappa| = 1.0$제어 불가

understeer gradient · $K_{us}$

rad·s²/m정상상태 응답

횡가속도 증가에 따라 운전자가 추가로 돌려야 하는 조향각의 비율.

$K_{us} \;=\; \dfrac{W_f}{C_f} \;-\; \dfrac{W_r}{C_r}$   ·   $W = \text{축 하중}, \; C = \text{코너링 강성}$
부호의미예
$K_{us} > 0$understeer (안전)양산차 기본
$K_{us} = 0$neutral steer—
$K_{us} < 0$oversteer (위험)F1 / 드리프트
A4 targetBMW_5 ± 80%0.003

A4 에서 정상상태 도달 못하면 부호 자체가 틀린 값 (e.g. staff −2547) → 0점.

load transfer ratio · LTR

무차원전복 지표

좌우 휠 사이의 수직 하중 차이 비율. 부호: 우측 하중 큼 (+).

$\text{LTR} \;=\; \dfrac{F_{zR} - F_{zL}}{F_{zR} + F_{zL}} \quad\in\;[-1,\, +1]$
임계값상태
정상$|\text{LTR}| < 0.3$일상 코너링
위험 (P1 임계)$|\text{LTR}| > 0.6$전복 마진 감소
전복$|\text{LTR}| = 1.0$한쪽 휠 완전 부상

명세 P1 임계 0.6 = BMW_5 세단 기준. SUV 면 0.7–0.8.
